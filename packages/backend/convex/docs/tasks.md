# Model: Tasks

## Overview
User-created tasks for organizing and tracking work. Tasks can be associated with agents and have time logs for time tracking. Tasks are owned by users and can be deleted (which also deletes associated time logs).

---

## Schema

### Description
Represents a user task or project. Tasks can have a title and optional description, and are used to organize agents and track time spent on work. When a task is deleted, all associated time logs are also deleted.

### Fields
- `_id`: Id<"tasks">  
  Primary key. Auto-generated by Convex.

- `userId`: string  
  References the authenticated user. Task belongs to a user.

- `title`: string  
  Required. Task title/name.

- `description`: string | undefined  
  Optional. Task description or notes.

- `createdAt`: number  
  Required. Timestamp (milliseconds) when task was created.

---

## Relationships
- Many Tasks → One User (`userId`)
- One Task → Many Agents (`taskId` in agents table)
- One Task → Many TimeLogs (`taskId` in timeLogs table)

---

## Indexes & Constraints
- Index: `by_user` on `userId`
- Index: `by_user_created` on `(userId, createdAt)`
- Non-null: `userId`, `title`, `createdAt`
- Validation:
  - `title` is trimmed before storage
  - `description` is trimmed and can be undefined
  - Deleting a task cascades to delete all associated time logs
