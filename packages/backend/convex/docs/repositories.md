# Model: Repositories

## Overview
User-saved GitHub repository URLs and names for quick selection in forms. Users can save frequently used repositories to avoid typing URLs repeatedly.

---

## Schema

### Description
Storage for user's saved GitHub repositories. Each record contains both the repository URL and a display name. Used to populate dropdowns and autocomplete fields in the UI. Users can save multiple repositories, and the entire list is replaced on each save operation.

### Fields
- `_id`: Id<"repositories">  
  Primary key. Auto-generated by Convex.

- `userId`: string  
  References the authenticated user. Repository belongs to a user.

- `url`: string  
  Required. Full repository URL (e.g., "https://github.com/user/repo").

- `name`: string  
  Required. Display name for the repository (e.g., "user/repo").

- `createdAt`: number  
  Required. Timestamp (milliseconds) when repository was saved.

---

## Relationships
- Many Repositories → One User (`userId`)

---

## Indexes & Constraints
- Index: `by_user` on `userId`
- Non-null: `userId`, `url`, `name`, `createdAt`
- Validation:
  - Repository URLs are stored as-is (no format validation)
  - Users can have multiple repositories with the same URL (no uniqueness constraint)
