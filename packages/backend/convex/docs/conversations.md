# Model: Conversations

## Overview
Stores conversation threads between users and AI agents. Each conversation contains an array of messages matching the Cursor API format, including user messages, assistant messages, tool calls, and tool results.

---

## Schema

### Description
Represents a conversation thread for an agent. Conversations are synced from the Cursor API and stored locally for offline access and faster loading. Messages follow the Cursor API message format with support for different message types.

### Fields
- `_id`: Id<"conversations">  
  Primary key. Auto-generated by Convex.

- `agentId`: string  
  Required. External agent ID from Cursor (e.g., `bc-109be4f0-c6b3-4112-8a2e-4ef48e65486d`). Usually matches `conversationId`.

- `userId`: string  
  Required. References the authenticated user. Conversation belongs to a user.

- `conversationId`: string  
  Required. Conversation ID from Cursor API (usually same as `agentId`).

- `messages`: Array<Message>  
  Required. Array of conversation messages in Cursor API format.

  Message object structure:
  - `id`: string - Unique message identifier
  - `type`: "user_message" | "assistant_message" | "tool_call" | "tool_result" - Message type
  - `text`: string | undefined - Message text content
  - `toolName`: string | undefined - Tool name (for tool_call/tool_result)
  - `toolInput`: any | undefined - Tool input parameters (for tool_call)
  - `toolResult`: string | undefined - Tool execution result (for tool_result)

- `updatedAt`: number  
  Required. Timestamp (milliseconds) of last update. Used for ordering and sync detection.

---

## Relationships
- Many Conversations → One User (`userId`)
- One Conversation → One Agent (`agentId` matches agent's `agentId`)

---

## Indexes & Constraints
- Index: `by_user` on `userId`
- Index: `by_agent` on `agentId`
- Unique index: `by_user_agent` on `(userId, agentId)`
- Index: `by_conversation` on `conversationId`
- Non-null: `agentId`, `userId`, `conversationId`, `messages`, `updatedAt`
- Validation:
  - `agentId` and `conversationId` are usually the same value
  - Each user can have only one conversation per agent
  - Messages array follows Cursor API message format
  - Message types must be one of: user_message, assistant_message, tool_call, tool_result
