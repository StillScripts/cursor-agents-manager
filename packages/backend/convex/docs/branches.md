# Model: Branches

## Overview
User-saved branch names for quick selection in forms. Users can save frequently used branch names (e.g., "main", "develop", "feature/new-feature") to avoid typing them repeatedly.

---

## Schema

### Description
Simple storage for user's saved branch names. Used to populate dropdowns and autocomplete fields in the UI. Users can save multiple branches, and the entire list is replaced on each save operation.

### Fields
- `_id`: Id<"branches">  
  Primary key. Auto-generated by Convex.

- `userId`: string  
  References the authenticated user. Branch belongs to a user.

- `name`: string  
  Required. Branch name (e.g., "main", "develop", "feature/new-feature").

- `createdAt`: number  
  Required. Timestamp (milliseconds) when branch was saved.

---

## Relationships
- Many Branches → One User (`userId`)

---

## Indexes & Constraints
- Index: `by_user` on `userId`
- Non-null: `userId`, `name`, `createdAt`
- Validation:
  - Branch names are stored as-is (no format validation)
  - Users can have multiple branches with the same name (no uniqueness constraint)
