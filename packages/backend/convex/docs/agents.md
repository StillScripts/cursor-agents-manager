# Model: Agents

## Overview
Represents AI agents created through Cursor or Claude Code providers. Each agent tracks the execution state, source repository, target branch/PR information, and can be associated with user tasks. Agents are synced from external APIs and support soft deletion.

---

## Schema

### Description
Stores agent metadata and execution state for background AI agents that perform code generation tasks. Agents are owned by users and can optionally be linked to tasks for time tracking purposes.

### Fields
- `_id`: Id<"agents">  
  Primary key. Auto-generated by Convex.

- `agentId`: string  
  External ID from Cursor API (e.g., `bc-109be4f0-c6b3-4112-8a2e-4ef48e65486d`). Unique identifier from the provider.

- `userId`: string  
  References the authenticated user. Agent belongs to a user.

- `provider`: "cursor" | "claude-code"  
  Required. The AI provider that created this agent.

- `taskId`: Id<"tasks"> | undefined  
  Optional. References `Tasks._id`. Links agent to a user task for time tracking.

- `name`: string  
  Required. Display name of the agent/task.

- `status`: "CREATING" | "RUNNING" | "FINISHED" | "ERROR" | "EXPIRED"  
  Required. Current execution state of the agent.

- `model`: string | undefined  
  Optional. AI model used by the agent (e.g., "gpt-4", "claude-3-opus").

- `summary`: string | undefined  
  Optional. Text summary of the agent's work/completion.

- `audioSummary`: string | undefined  
  Optional. Base64 encoded audio data for audio summary playback.

- `sourceRepository`: string  
  Required. Source repository URL where the agent operates.

- `sourceRef`: string | undefined  
  Optional. Source branch/ref name (e.g., "main", "develop").

- `targetBranchName`: string | undefined  
  Optional. Target branch name where changes will be applied.

- `targetUrl`: string | undefined  
  Optional. URL to view the target changes.

- `targetPrUrl`: string | undefined  
  Optional. Pull request URL if a PR was created.

- `targetAutoCreatePr`: boolean | undefined  
  Optional. Whether to automatically create a PR.

- `providerData`: any | undefined  
  Optional. Additional provider-specific metadata stored as JSON.

- `syncStatus`: "synced" | "stale" | "error" | undefined  
  Optional. Status of last sync operation with external API.

- `syncError`: string | undefined  
  Optional. Error message if sync failed.

- `updatedAt`: number  
  Required. Timestamp (milliseconds) of last update. Used for ordering and sync detection.

- `deletedAt`: number | undefined  
  Optional. Timestamp (milliseconds) when agent was soft-deleted. `undefined` means not deleted.

---

## Relationships
- Many Agents → One User (`userId`)
- Many Agents → One Task (`taskId`, optional)

---

## Indexes & Constraints
- Index: `by_user` on `userId`
- Unique index: `by_user_agent` on `(userId, agentId)`
- Index: `by_user_status` on `(userId, status)`
- Index: `by_updated_at` on `updatedAt`
- Index: `by_agent_id` on `agentId`
- Index: `by_task` on `taskId`
- Non-null: `agentId`, `userId`, `provider`, `name`, `status`, `sourceRepository`, `updatedAt`
- Validation:
  - `status` must be one of: CREATING, RUNNING, FINISHED, ERROR, EXPIRED
  - `provider` must be "cursor" or "claude-code"
  - `deletedAt` is undefined for active agents
  - `audioSummary` is cleared when `summary` is updated
